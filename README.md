# PDF to Word Replica using Python

## Project Overview
This project recreates a given legal PDF document into an MS Word (.docx) file using Python.  
The generated Word document closely matches the original PDF in terms of layout, tables, headings, alignment, and formatting.

The Word file is created **programmatically** using Python — not manually.

---

## Technologies Used
- Python 3.x
- python-docx
- Visual Studio Code
- Microsoft Word

---

## Features
- Accurate table replication
- Proper text alignment and spacing
- Bold headings and section titles
- Placeholder support (e.g. {{client_name}}, {{address}})
- Clean and reusable Python code
